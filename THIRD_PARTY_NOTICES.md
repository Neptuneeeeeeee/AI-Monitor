# Third-party provenance review

Status: review pending; not a completed license audit.

The Swift package currently declares no remote package dependencies. Collectors use Python standard-library modules. This does not establish that every implementation and asset is wholly original.

Historical development references included CodexBar and Kimi Code repositories. They remain only in the private pre-migration backup, not in this public tree. Before distribution, determine whether actual code was incorporated, identify the relevant versions/licenses, and retain any required notices. Do not assume reference-only use proves the absence of copied code.

Brand asset source URLs are retained in `Resources/BrandAssets/sources.json` and `docs/BRAND_ASSETS.md`. Identification of the source is not itself a redistribution license. Review each applicable brand/asset policy. The application icon is generated by `scripts/make_app_icon.swift`; provider brand icons are separate.
