**Apple Silicon (serie M) · macOS 14 o posterior · Python incluido**

Abre el DMG, arrastra **AI Monitor.app** a **Aplicaciones** y elige tus servicios en Ajustes. No necesitas instalar Python, Xcode ni Homebrew. Algunos servicios requieren su cliente oficial y una sesión iniciada.

> **Versión preliminar:** sin firma Developer ID ni notarización de Apple. macOS puede bloquear el primer inicio. Lee la [guía de instalación](../INSTALL.md) y verifica el origen antes de decidir si la abres. No desactives la seguridad del sistema.

## De un vistazo

- Consulta la cuota restante y su reinicio, con indicadores monocromos en la barra de menús.
- Elige qué planes aparecen y ordénalos a tu gusto.
- Cambia a los saldos de API y gastos del día cuando el proveedor los facilite.

## Servicios compatibles

**Suscripciones:** Claude · Codex · Kimi · GitHub Copilot · Antigravity · Cursor · GLM · MiniMax · Windsurf · Kiro

**Conexiones API:** DeepSeek · Kimi · OpenAI · Claude · SiliconFlow · OpenRouter. Google AI Studio: solo comprobación de acceso, sin importes de facturación.

Las funciones dependen del proveedor y de la cuenta. Windsurf muestra datos de caché, no lecturas en tiempo real. Consulta los [detalles de compatibilidad](../PROVIDER_CAPABILITIES.md).
