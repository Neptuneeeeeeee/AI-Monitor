# AI Monitor

Suas cotas de planos de IA na barra de menus do macOS.

**Apple Silicon (série M) · macOS 14 ou superior · Python incluído**

Abra o DMG, arraste **AI Monitor.app** para **Aplicativos** e escolha os serviços nos ajustes. Não é necessário instalar Python, Xcode ou Homebrew. Alguns serviços ainda exigem o cliente oficial e uma sessão iniciada.

> **Versão de prévia:** sem assinatura Developer ID nem notarização da Apple. O macOS pode bloquear a primeira abertura. Leia o [guia de instalação](../INSTALL.md) e confira a origem antes de decidir abrir o app. Não desative a segurança do sistema.

## Tudo em um só lugar

- Veja as cotas restantes e os horários de renovação com indicadores monocromáticos na barra de menus.
- Escolha os planos exibidos e organize a ordem.

## Serviços compatíveis

**Assinaturas:** Claude · Codex · Kimi · GitHub Copilot · Antigravity · Cursor · GLM · MiniMax · Windsurf · Kiro · OpenCode Go · ClinePass

Os dados disponíveis dependem do provedor e da conta. O Windsurf mostra dados em cache, não leituras em tempo real. Consulte os [detalhes de suporte](../PROVIDER_CAPABILITIES.md).
