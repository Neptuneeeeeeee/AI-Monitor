# 交互预览（模拟数据）

构建后运行打包应用的可执行文件并传 `--demo`，或从工作区运行 `bash public/scripts/preview.sh`。此模式使用真实SwiftUI/AppKit视图，但应用store与API store均为servicesEnabled=false，全部套餐和API数字均为合成数据。预览窗口顶部始终显示标记。可切换新增/全部套餐、排序/启用、显示设置、API页面和编辑页；外部连接、账单跳转、密钥写入/删除、缓存删除、数据目录和开机启动均在store层拒绝。偏好保存在临时独立domain，正常退出时移除。关闭窗口或按⌘Q即可退出预览。

本模式不安装或替换旧Monitor，也不迁移真实账号。菜单栏的黑白横杠在预览标题区演示，预览不新增一个难以辨识的后台菜单栏实例。正式读取仍需正常打开应用并主动启用账号。

`--demo --demo-self-test --demo-receipt <绝对路径>` 会在真实窗口中检查离线交互与阻断行为，输出检查结果后自动退出；不进行真实凭据读写。
