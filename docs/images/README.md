# README screenshots / 文档截图

The `en/` and `zh-CN/` folders each contain four images: an overview, subscription quotas, plan settings, and API balances. Every amount, quota and account status is a synthetic example.

Screenshots were rendered from the real SwiftUI/AppKit production views at the source commit recorded in `manifest.json`, with collectors and account services disabled. English labels were translated in a disposable checkout for documentation capture only. The v1.9.4 release interface remains mainly Chinese; the README language links do not change the app language. The surrounding backgrounds, titles and captions are presentation framing, not additional application features.

No real account screenshot, API key, email address, local file path or private workspace content is included. Provider logos come from the existing bundled assets; see [brand sources](../BRAND_ASSETS.md). Image hashes and sizes are in [manifest.json](manifest.json).
