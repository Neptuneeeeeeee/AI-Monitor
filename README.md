**Apple Silicon (M-series) · macOS 14+ · Python included**

Open the DMG, drag **AI Monitor.app** into **Applications**, then choose your plans in Settings. No Python, Xcode or Homebrew installation needed. Provider clients and sign-in may still be required.

> **Preview build:** not signed with Developer ID or notarized by Apple. macOS may block the first launch; read the [installation guide](docs/INSTALL.md) before deciding to open it. Do not disable system security.

## At a glance

- See remaining quota, reset times and monochrome menu bar indicators.
- Choose which plans appear and arrange them in your preferred order.
- Switch to API balances and daily costs where the provider supports them.

## Supported services

**Plans:** Claude · Codex · Kimi · GitHub Copilot · Antigravity · Cursor · GLM · MiniMax · Windsurf · Kiro

**API connections:** DeepSeek · Kimi · OpenAI · Claude · SiliconFlow · OpenRouter. Google AI Studio: access check only, no numeric billing.

Features depend on the provider and account. Windsurf readings are cached, not live. See the [capability details](docs/PROVIDER_CAPABILITIES.md) for limits and connection requirements.
